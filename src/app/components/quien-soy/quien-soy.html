Juego propio: El Rosco

El Rosco es un juego de preguntas y respuestas inspirado en el programa Pasapalabra. El objetivo es completar todas las letras del rosco antes de que se termine el tiempo o se agoten las vidas disponibles.

¿Cómo se juega?

  • Cada letra del abecedario tiene asociada una pregunta.
  • El jugador debe escribir la respuesta correspondiente.
  • Si la respuesta es correcta, la letra se marca en verde y se suman puntos.
  • Si la respuesta es incorrecta, la letra se marca en rojo y se pierde una vida.
  • Si el jugador no sabe la respuesta, puede usar el botón Pasapalabra para dejar esa letra pendiente y continuar con la siguiente.
  • Las letras pendientes volverán a aparecer más adelante hasta que todas hayan sido respondidas.

Condiciones de victoria

  • El jugador gana si logra completar todas las preguntas del rosco antes de que se termine el tiempo o se quede sin vidas.

Sistema de puntos

  • Cada respuesta correcta suma 2 puntos.
  • Las respuestas incorrectas descuentan vidas.
